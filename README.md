# English Quest 2.0

Combined playable build: original 180-verb learning system, progress and cooldown rules, illustrated world, furniture and six buildings.

Upload the **contents** of this folder to a new GitHub repository, enable Pages from main / root. Do not upload the ZIP itself as a file.

The original save key is retained, so progress can be carried over when the same browser origin is used; a new GitHub Pages repository has a different origin and will normally start fresh.

The 180 quest IDs remain stable (124 outdoors, 56 in original interior challenge maps). Extra rooms are exploratory.
